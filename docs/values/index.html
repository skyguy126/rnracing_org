Our Values

Leadership principles. We wrote them down so the chaos looks intentional.

  • Torque Specs

    Every bolt is torqued to a number we asked a chatbot for. We then wrote it down with extreme confidence. Please do not check the service manual.

    Source
    Trust me bro

  • It don't matter

    Wrong part? It don't matter. Doesn't fit? It don't matter. Check engine light? Electrical tape. It don't matter. This is not a strategy. It is the only strategy.

    Torque Spec
    It don't matter

  • Ego

    We are never wrong. Not even when we are. Especially when we are. If the car is on fire, we just upgraded the heater.

    Mistakes admitted
    Zero

  • Zip Ties Are Structural

    Zip ties, duct tape, Loctite, and JB Weld: the holy quartet of load-bearing components. If it moves and it should not, tape. If it still moves, JB Weld. If it does not move and it should, hammer.

    Rated load
    Enough

  • Paint Pen = Inspected

    One stripe of paint pen on a bolt means it has been torqued, verified, and blessed. By us. Once. Probably on a day we were not tired.

    Bolts marked
    Most of them

  • Crashes Are Content

    If the camera wasn't rolling, it didn't happen. If the camera was rolling, deflect. Either way we're posting it.

    Views per crash
    Dozens

  • The Camry Is Fine

    It's a '96 Camry. It's competing in an endurance race. It is fine. Stop asking. Do not look under it.

    Status
    Fine

  • Measure Once, Cut Twice

    The first cut is a learning experience. The second cut is where we act like we planned it. There is no third cut. We ran out of tube.

    Tolerance
    ± a lot

  • Receipts Are a Rumor

    The budget is a suggestion and we have no memory of what anything cost. If you ask the treasurer, he'll point you to Nyle's fruit stand.

    Money spent
    Yes

These values are non-binding, unverified, and were written with heavy use of AI. If you disagree with any of them, you're wrong. AI is never wrong. If you disagree, you're coping.
